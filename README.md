# 🎨 Meme & Resim Oluşturucu

Discord için özel tasarlanmış profesyonel meme oluşturma araçları.

## 🚀 Özellikler

- ✅ Gelişmiş Meme Oluşturucu (Popüler template'ler)
- ✅ Dinamik Resim Oluşturucu (URL parametreleri)
- ✅ Statik Resim Oluşturucu (İndir ve paylaş)
- ✅ Discord Embed Desteği

## 📸 Discord'da Nasıl Kullanılır?

### Yöntem 1: Statik Resim (ÖNERİLEN)
1. [Meme Oluşturucu](https://teyetdgd.github.io/test-site/create-static-image.html) sayfasına git
2. Meme'ini oluştur
3. "📥 Görseli İndir" butonuna tıkla
4. İndirilen resmi Discord'a yükle

### Yöntem 2: GitHub Issues (Dinamik URL)
1. Meme'ini oluştur ve indir
2. Bu repo'da yeni bir Issue aç
3. Resmi Issue'ya sürükle-bırak
4. GitHub'ın otomatik oluşturduğu CDN URL'sini kopyala
5. Bu URL'yi Discord'da paylaş

### Yöntem 3: Imgur Upload
1. Meme'ini oluştur ve indir
2. [Imgur](https://imgur.com/upload) üzerinden yükle
3. Direkt link'i Discord'da paylaş

## ⚠️ Önemli Not

GitHub Pages, dinamik resim oluşturmayı desteklemez çünkü statik bir hosting servisidir. Discord'un resmi görmesi için:

- **Statik resim dosyaları** kullanın (önerilen)
- **Resmi indirip Discord'a yükleyin** (en kolay)
- **Imgur/GitHub Issues** gibi resim hosting servisleri kullanın

## 🛠️ Teknik Detaylar

- **Frontend:** Vanilla JavaScript, HTML5 Canvas
- **API:** Imgflip Meme API
- **Hosting:** GitHub Pages
- **Resim Formatı:** PNG (800x400)
